# Truco Criollo — versión web

Truco argentino mano a mano, a 30, sin flor. Con usuarios, amigos, torneos y desafíos.

- Jugar: abrir la página en el navegador del celular.
- iPhone: Safari → Compartir → **Agregar a pantalla de inicio**.
- Android: Chrome → menú ⋮ → **Agregar a la pantalla principal** (o instalar el APK).

Usa el mismo servidor que la app de Android: jugadores de iPhone y Android juegan entre sí.
